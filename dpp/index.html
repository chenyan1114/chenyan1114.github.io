      技術細節
      
    
        
  • 簽名：proof options 與 VC 各自 JCS 正規化 → SHA-256 → 串接 → 用簽名金鑰簽名 → proofValue，連同 proof options 成為 proof。
    • 
        
  • did:key → eddsa-jcs-2022（W3C 標準），驗證用 DID 內的公鑰。
    • 
        
  • did:web → 同樣用 eddsa-jcs-2022，驗證時從 https://網域/.well-known/did.json 下載 DID 文件取得公鑰；
          尚未放上網站時，以本頁暫存的文件模擬並提醒。
    • 
        
  • did:ethr → ecdsa-secp256k1-recovery-jcs-demo（教學用，非標準）：從簽名回推地址，
          再比對 DID 文件裡的 #controller 或 #delegate-N；連不上 RPC 時離線判定。
    • 
        
  • VC v2.0：validFrom／validUntil 取代 v1 的 issuanceDate／expirationDate，皆為選填的 ISO 8601 日期時間。
    • 
        
  • 驗證結果：✗ 違反 v2.0 規範或簽名不符；⚠ 只是本 demo 的預期（如 urn:uuid、ISO claims、與表單不同）。
